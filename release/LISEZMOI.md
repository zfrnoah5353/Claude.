# SkyLyrics 1.0.0 (Minecraft 1.21.11, Fabric)

Paroles Spotify synchronisées, affichées mot par mot en 3D dans le ciel, avec une barre de paroles en haut de l'écran, 12 styles, 14 polices et 10 ciels personnalisés.

## Installation
1. Installe Fabric Loader pour 1.21.11 : https://fabricmc.net/use/installer/
2. Télécharge Fabric API pour 1.21.11 : https://modrinth.com/mod/fabric-api
3. Mets `skylyrics-1.0.0.jar` et le jar de Fabric API dans `%appdata%\.minecraft\mods`
4. Lance le profil « fabric-loader-1.21.11 ».

## Utilisation
- Lance un son dans l'appli Spotify (Windows : rien à configurer, pas de compte).
- **K** ouvre le menu : Paroles, Styles, Ciels, Aperçu.
- « Essayer dans le ciel » lance une démo sans Spotify.
- Paroles en retard ou en avance ? Menu > Paroles > Décalage synchro.

Paroles : lrclib.net (gratuit). Polices : Google Fonts (licence OFL, voir FONTS-OFL.txt dans le jar).
